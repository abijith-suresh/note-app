# note-app — agent brief

Local-first markdown notes that live in the browser.

## The Project

interleaf is a calm scratchpad for short-lived work notes: it opens straight into writing, keeps everything in the browser with no account, backend, or sync, and treats export (txt, Markdown, ZIP) as the backup path. Notes are disposable by design — no folders, backlinks, or long-lived knowledge management.

The product name is `interleaf` while the repo is `note-app`; both are intentional, and renaming either is an owner decision.

Status: dormant — no feature work since Aug 2026.
